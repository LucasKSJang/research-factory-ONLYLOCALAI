Privacy Policy

Local Research Factory · Luminex Enterprise · Last updated 2 August 2026
In short: this is a personal tool that runs on one private computer. It publishes summaries of research the operator produced themselves. It does not read, collect, store, or analyse other people's data, and it sends nothing to any third party.

1. Who this covers

This policy covers the application Local Research Factory, operated by Lucas Jang under Luminex Enterprise. The application is self-hosted software that runs entirely on the operator's own computer. It is not a hosted service, it has no users other than the operator, and it does not accept sign-ups.

2. What the application does

The application gathers publicly available web pages, produces short research summaries using open-source language models that run locally on the operator's own hardware, and publishes those summaries to the operator's own social accounts.

3. Data collected from social platforms

None. Specifically, the application does not:

  • read, download, or store posts, profiles, connections, or messages belonging to any member;
  • search, scrape, or index platform content;
  • build profiles of, or perform analytics on, any person;
  • use platform data to train any model.

Platform access is write-only. The only API operation used is publishing a post to the operator's own account.

4. Data stored

The application stores, on the operator's own computer only:

  • OAuth access and refresh tokens, used solely to publish to the operator's own account;
  • Research reports and drafts generated by the application, containing publicly available information and the application's own summaries of it.

Nothing is transmitted to any server operated by Luminex Enterprise, because there is none. No database, no cloud storage, no logging service.

5. Third parties

No data is sold, rented, shared, or otherwise disclosed to any third party. The application makes outbound requests only to: public web pages being researched, the social platform APIs used to publish, and a language model running on the operator's own machine. There are no analytics providers, advertising networks, or trackers.

6. Cookies and tracking

The application has no web interface for other people and sets no cookies. This policy page itself is static and contains no scripts, cookies, or trackers.

7. Retention and deletion

Tokens are kept only while the integration is in use and are deleted when access is revoked or the application is removed. Generated reports remain on the operator's computer until deleted manually.

8. Revoking access

The operator can revoke this application's access at any time from the connected platform's settings — for LinkedIn, under Settings & Privacy → Data privacy → Other applications → Permitted services. Revocation immediately and permanently ends the application's ability to publish.

9. Children

The application is not directed at children and collects no data from anyone, including children.

10. Changes

Any change to this policy will be published at this URL with an updated date above. The full revision history is public in the source repository.

11. Contact

Questions about this policy can be raised as an issue in the public source repository: github.com/LucasKSJang/research-factory-ONLYLOCALAI/issues.

The application's full source code is public at github.com/LucasKSJang/research-factory-ONLYLOCALAI, so every claim on this page can be checked against the code.
